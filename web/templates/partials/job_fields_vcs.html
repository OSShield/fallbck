{{/* Git repository (VCS) job fields. */}} {{define "job-fields-vcs"}}
The agent keeps a bare mirror of every repository in its VCS state directory and fetches only what changed; each run writes one snapshot with every mirror (branches, tags, merge and pull request heads, LFS objects, wikis, GitHub gists) and a restore script. Needs git 2.31 or newer on the agent, and git-lfs for LFS repositories.
Manage connections
Empty: every project the token can see (an administrator's token sees all; not allowed on gitlab.com). The token's own login includes its private repositories; other users give their public ones.
A match on a group leaves out everything below it. Globs on owner/name; explicit repositories and gists are always kept.
LFS objects not counted; GitLab reports sizes to tokens with the Reporter role or higher. LFS objects not counted; explicit repositories are skipped too when larger.
Use a token kept on the agent (fallbck-agent vcs profile create) instead of the connection's; the server never hands out its token for such a job.
