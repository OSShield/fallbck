{{/* Git repository (VCS) job fields. */}} {{define "job-fields-vcs"}}
The agent keeps a bare mirror of every repository in its VCS state directory and fetches only what changed; each run writes one snapshot with every mirror (branches, tags, merge request heads, LFS objects, GitLab wikis) and a restore script. Needs git 2.31 or newer on the agent, and git-lfs for LFS repositories.
Manage connections
Empty: every project the token can see (an administrator's token sees all; not allowed on gitlab.com).
A match on a group leaves out everything below it.
LFS objects not counted; GitLab reports sizes to tokens with the Reporter role or higher.
Use a token kept on the agent (fallbck-agent vcs profile create) instead of the connection's; the server never hands out its token for such a job.
