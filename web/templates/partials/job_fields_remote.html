{{/* Remote storage job fields. */}} {{define "job-fields-remote"}}
The agent lists the roots and reads every object; nothing is ever written to the remote. Objects keep their size and modification time, so later runs reuse unchanged data in PBS. With one snapshot per root each root gets its own snapshot group (<job group>-<root>) and the job's own group holds the run manifest.
Manage remotes
Bucket, optionally with a prefix: bucket or bucket/prefix.
* doesn't cross /; a pattern that matches a directory takes everything below it.
Use a credential kept on the agent (fallbck-agent remote profile create) instead of the remote's; the server never hands out its credential for such a job.
