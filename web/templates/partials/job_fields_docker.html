{{/* Docker host job fields. */}} {{define "job-fields-docker"}}
Always included: docker inspect of every container, network and volume, the compose config files named in the container labels (plus .env), /etc/docker/daemon.json, image references with digests, and a generated restore script. Every named volume is archived file by file as vol-<name>. Bind mounts are listed in the manifest but not archived (use a filesystem job). Label a container or volume fallbck.io/skip=true to leave it out; label a container fallbck.io/pause=true to pause it while its volumes are copied.
{{end}}
