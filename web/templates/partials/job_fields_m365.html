{{/* Microsoft 365 job fields. */}} {{define "job-fields-m365"}}
Every user, SharePoint site and team becomes its own snapshot group (<job group>-user-<upn>, -site-<url>, -team-<name>); the job's own group holds the Entra ID directory and the run manifest. Use a PBS target whose namespace is dedicated to the tenant and give it a prune job. Mailbox items are stored in Exchange's export format (.exoitem, restorable only through an Exchange Online import) with an index.json per folder; files and Teams messages are stored as they are. After the first run only changed items are fetched.
